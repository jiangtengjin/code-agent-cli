## 一、设计风格定位

### 1.1 设计原则

```
Terminal Native（终端原生）—— 所有设计尊重终端环境，不做"Web 界面模拟终端"
```

| 原则 | 说明 |
|------|------|
| **终端诚实** | 不模拟浏览器体验，所有组件在 256 色终端中都能正常工作 |
| **密度优先** | 信息密度高，垂直空间高效利用，反对过度留白 |
| **打字机风格** | 等宽字体贯穿所有表面，响应即内容 |
| **白字黑底** | 纯黑底 + 纯白主字，极致对比度，长时间阅读不疲劳 |
| **多彩语义** | 不同功能角色赋予不同颜色，一目了然 |
| **可扫描性** | 每个界面元素设计都为了让用户快速扫读，而非阅读 |

### 1.2 色彩体系

参考竞品：OpenCode（极黑底）、Claude Code（终端自适应）、Warp（块分割）

```
调色板（纯黑底 + 白字 + 多彩语义色，无绿色）：

  BG 底色    #000000  (纯黑——终端真实黑色)
  BG 面板    #0D0D0D  (近黑——用于面板/分割)
  BG 悬浮    #1A1A1A  (悬浮/选中态背景)
  BG 表面    #262626  (输入框/代码块背景)
  BG 表面低   #1A1A1A  (次要表面)

  TEXT 主色   #FFFFFF  (纯白——主内容、用户输入)
  TEXT 次要   #9CA3AF  (灰——辅助信息/时间戳/Token计数)
  TEXT 占位   #4B5563  (深灰——占位符/禁用态)

  ——— 多色语义系统（按功能角色分配，互不冲突） ———

  BLUE    #60A5FA  → AI 消息、信息提示、链接
  PURPLE  #A78BFA  → 思考过程、Brain dump、内部推理
  CYAN    #67E8F9  → 代码、文件路径、技术符号
  ORANGE  #FBBF24  → 警告、高亮、建议、注意
  RED     #F87171  → 错误、危险操作、删除
  PINK    #F472B6  → 工具调用、函数名称

  ——— Agent 动态效果色（彩虹渐变，用于思考/Streaming） ———
  RAINBOW  →  BLUE → CYAN → PURPLE → PINK → 循环

  语义色对照：
    ERROR   #F87171  (红色——错误/危险操作)
    WARN    #FBBF24  (橙色——警告)
    SUCCESS #34D399  (青色——成功，非绿色调)
    INFO    #60A5FA  (蓝色——信息)
```

### 1.3 排版

| 层级 | 样式 | 用途 |
|------|------|------|
| Chrome | JetBrains Mono / IBM Plex Mono 13px | 状态栏、模式标签、辅助信息 |
| Body | JetBrains Mono / IBM Plex Mono 14px | 对话内容、用户输入、tool call |
| Code | JetBrains Mono / IBM Plex Mono 14px | 代码块、diff |
| Heading | 同 Body 但 bold + 语义色 | 消息中的标题、分隔 |

### 1.4 间距 & 圆角

```
4px 网格系统：2 / 4 / 8 / 12 / 16 / 24 / 32 / 48

圆角：统一 4px（硬朗终端风格，不做圆润处理）
边框：1px solid，用 BG 表面 或 语义色
分割线：─ ─ ─ 风格，不使用实线 ━━━
```

### 1.5 交互语言

| 交互 | 表达 |
|------|------|
| **白色光标闪烁** | 输入框就绪，等待用户操作 |
| **蓝色左边框 + 亮度** | 当前激活/选中的消息块 |
| **旋转动画 (⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏)** | 加载中 / 思考中 |
| **逐字出现 + 彩虹渐变动效** | Streaming 输出，Agent 思考过程动态展现 |
| **蓝色勾 ✓** | 操作成功确认 |
| **红色底 + 白色字** | 错误 / 危险确认弹窗 |

## 二、原型页面清单

我将把所有原型图按功能域划分为 **4 个 HTML 文件**：

| 文件 | 内容 | 说明 |
|------|------|------|
| `prototype-01-core.html` | 核心对话流程（欢迎屏、对话主界面、Streaming、工具调用展示） | **核心业务** |
| `prototype-02-modes.html` | 四种对话模式界面（Normal / Auto / Plan / Edit） | **模式设计** |
| `prototype-03-system.html` | 系统界面（配置向导、Slash命令、权限确认、Cost统计） | **系统功能** |
| `prototype-04-workspace.html` | 工作区界面（多会话管理、文件diff、RAG搜索、/goal任务模式） | **增强功能** |

## 四、交互设计要点

### 4.1 键盘导航

| 按键 | 功能 |
|------|------|
| `Tab` | 轮询切换对话模式 (Normal → Auto → Plan → Edit) |
| `Ctrl+P` | 命令面板 |
| `Ctrl+C` | 中断当前输出 |
| `↑ ↓` | 历史输入 / 消息导航 |
| `ESC` | 取消当前操作 / 关闭弹窗 |
| `Y/n` | 确认 / 取消（权限弹窗） |

### 4.2 消息分块 (借鉴 Warp Block 模型)

每条用户消息 + AI 响应 = 一个 `Block`：
- 角色识别的左边框颜色 (User=无/AI=Accent/System=Dim)
- 可折叠工具调用段落
- 独立的复制/引用操作

### 4.3 Streaming 状态指示

``` 
AI 思考时:    ┌─ ▶ 思考过程 ───── 可折叠 ─┐
              │  ◌ 当前动作                │
              │  ✓ 已完成动作               │
              └──────────────────────────┘

AI 输出时:    文本光标逐字渲染
工具执行时:   每个工具调用卡片显示实时状态
```
