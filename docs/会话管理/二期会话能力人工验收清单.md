# 二期会话能力人工验收清单

> 版本：V1.0
> 日期：2026-07-25
> 适用范围：Code Agent CLI 二期会话能力人工验收
> 重点阶段：Phase 2B（恢复与列表），并覆盖与 `fork`、中断恢复相关的关键联动场景

---

## 1. 验收目标

本清单用于验证二期会话能力是否满足以下核心目标：

- 会话能够按工作区正确持久化与恢复
- 用户能够通过 `--continue`、`resume`、`/resume` 找回目标会话
- 恢复列表具备可读性，能正确展示状态、模式、最后活跃时间
- `resume --fork` 能创建分支会话，而不是污染原会话
- 中断会话能够被正确识别、提示并恢复
- 本阶段新增用户可见文案无乱码，且中文表达可读

---

## 2. 前置准备

执行验收前，请准备以下环境：

1. 开启会话持久化配置：

```json
{
  "sessions": {
    "enabled": true
  }
}
```

2. 准备两个工作区：
   - 工作区 `A`
   - 工作区 `B`

3. 在工作区 `A` 中准备以下会话样本：
   - 1 个普通会话
   - 1 个 `plan` 待确认会话
   - 1 个已归档会话
   - 1 个 `--prompt` 会话

4. 在工作区 `B` 中准备以下会话样本：
   - 1 个普通会话

5. 建议提前记录以下信息，便于核对恢复结果：
   - 会话编号
   - 会话标题
   - 会话模式
   - 会话状态
   - 最后活跃时间

## 4. 重点关注项

执行过程中，建议特别关注以下高风险点：

1. 是否恢复到了错误的会话
2. `resume --fork` 是否误修改父会话
3. `plan` 待确认状态是否在恢复后丢失
4. 中断恢复后是否出现自动重放执行
5. 工作区过滤是否失效，导致跨项目会话混入
6. 用户可见提示是否仍存在乱码或英文残留
